# 🚀 START HERE: Learn Node.js Backend, Step by Step

This is a **beginner-friendly path**. You don't need to be a senior developer.
Each level is one file. Each file tells you exactly:

1. 📖 **What to study**, with direct links to free courses and docs
2. ✅ **Check yourself**: questions you should be able to answer before moving on
3. 🛠️ **What to build**: one small project, broken into tiny steps, written **by you**
4. 🆘 **Where people get stuck**, plus how to ask me for help

> Rule: **Study a little → build a little.** Don't watch 20 hours of videos first.
> Spend about 30% of your time studying and 70% coding.

---

## The path (do these in order)

| Level | Topic | You will build | Time |
|---|---|---|---|
| [Level 0](level-0-setup-and-javascript.md) | Setup + JavaScript you need | 🎲 Number guessing game (terminal) | 1–2 weeks |

| [Level 4](level-4-databases.md) | Databases (SQL + PostgreSQL) | 📚 Books API, now saved in a real database | 2 weeks |
| [Level 5](level-5-authentication.md) | Login, passwords, JWT | 🔐 Add users + login to the Books API | 1–2 weeks |

| [Level 8](level-8-whats-next.md) | What to learn next | Ideas: chat app, file uploads, caching... | ongoing |

**Total: about 3–4 months** at 1–2 hours a day.

## How to work on each level

```
1. Read the level file top to bottom (5 min)
2. Do the "Study" links in order, taking notes in your own words
3. Answer the "Check yourself" questions (out loud or in a notes file)
4. Create the project folder and build it step by step. Commit to git after each step.
5. Stuck for more than 20 minutes? Ask me (see below)
6. Finished? Tick the box below and move to the next level
```

## 🆘 How to ask me for help when stuck

Paste this into the chat (fill it in):

```
Level: 3, Step: 4
What I'm trying to do: return a 404 when the book id doesn't exist
What I tried: (paste your code)
What happened: (paste the error or wrong output)
What I expected: ...
```

You can also say:
- **"Give me a hint, not the answer"**: I'll nudge you without writing the code for you.
- **"Review my code for Level 3"**: I'll read your project and point out bugs or improvements.
- **"Explain X like I'm a beginner"**: for any concept that doesn't click.
- **"Quiz me on Level 2"**: I'll test your understanding.
